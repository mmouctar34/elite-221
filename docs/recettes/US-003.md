Date : 26/10/2026. Version testée : `d4bd2b0`. Recette faite par Claude, selon les règles de l'agent `testeur-recette`.

| Critère | Verdict | Preuve |
|---|---|---|
| Après une première visite réussie, SPLEAD rouverte en mode avion affiche l'accueil, sans page d'erreur du navigateur | **Conforme (simulation) ; non vérifiable en vrai mode avion** | Version de production (`npm run build` puis `npm run preview`) : 1) première visite, le service worker s'active et garde 16 fichiers ; 2) rechargement, le service worker contrôle la page ; 3) **serveur arrêté**, vérifié : une requête au serveur échoue ; 4) rechargement : titre « SPLEAD », accueil « Bienvenue sur SPLEAD », 4 onglets, aucune page d'erreur, polices 500, 600 et 800 lues depuis le cache. |

## Cas difficiles vérifiés

- **Première visite sans service worker encore actif** : normal. L'ouverture hors-ligne est garantie à partir de la visite suivante, d'où le critère « après une première visite réussie ».
- **Nouvelle version** : le service worker est en mode « prompt » : une nouvelle version n'est jamais installée de force pendant l'utilisation (préparation de US-004).
- **Effacement des données** : l'application demande au navigateur un stockage persistant (important sur iPhone, voir ADR-001). Dans le navigateur de test, la demande est restée en attente : c'est normal pour une application non installée.

## Défauts trouvés

Aucun.

## Ce qui n'a pas pu être vérifié

Le vrai mode avion sur un téléphone Android : il faut une préversion en ligne (US-006) et le téléphone du fondateur.

## Verdict proposé : Acceptée sous condition

Conforme sur ordinateur et dans les tests. À confirmer en mode avion sur un téléphone (définition de « terminé », point 4).
