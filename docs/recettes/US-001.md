# Recette US-001 : Installer SPLEAD sur Android

Date : 26/10/2026. Version testée : `d4bd2b0`. Recette faite par Claude, selon les règles de l'agent `testeur-recette`.

| Critère | Verdict | Preuve |
|---|---|---|
| Sur Chrome pour Android, à la 2e visite, un bouton « Installer SPLEAD » est proposé, sans fenêtre imposée dès la première seconde | **Conforme dans les tests ; non vérifiable sur téléphone** | `src/pwa/pwa.test.tsx` : pas de bandeau à la 1re visite ; pas de bandeau tant que le navigateur ne propose pas l'installation ; bandeau à la 2e visite ; la fenêtre automatique du navigateur est bloquée (`defaultPrevented`) ; « Plus tard » ferme le bandeau ; une visite n'est comptée qu'une fois par session. Dans le navigateur : le compteur `splead.visites` vaut 1 après la première ouverture. **Manque** : l'essai sur un vrai téléphone Android, qui demande une adresse en ligne (US-006). |
| Une fois installée, SPLEAD s'ouvre en plein écran, avec l'icône et le nom SPLEAD, sans barre d'adresse | **Conforme sur ordinateur (conditions d'installation) ; non vérifiable sur téléphone** | Version de production ouverte dans le navigateur : manifeste présent et lu (`name` SPLEAD, `display` standalone, `start_url` /, icônes 64, 192, 512 et 512 « maskable ») ; service worker actif. Ce sont les conditions demandées par Chrome pour proposer l'installation. **Manque** : l'installation réelle sur un téléphone Android. |

## Cas difficiles vérifiés

- **Stockage bloqué** (navigation privée) : le comptage des visites ne plante pas ; testé.
- **Choix « Plus tard »** : le bandeau disparaît et ne revient pas pendant la session ; testé.
- **Proposition déjà utilisée** : après un premier essai d'installation, le bouton disparaît (Chrome n'autorise qu'un essai par proposition) ; testé.

## Défauts trouvés

Aucun.

## Ce qui n'a pas pu être vérifié

L'installation sur un vrai téléphone Android d'entrée de gamme. Il faut d'abord mettre une préversion en ligne (US-006 : compte Cloudflare et dépôt GitHub), puis faire l'essai avec le téléphone du fondateur.

## Verdict proposé : Acceptée sous condition

Tout ce qui se vérifie sans téléphone est conforme. La user story ne pourra être déclarée « Terminée » (définition de « terminé », point 4) qu'après l'essai sur un téléphone Android.

Décision écrite du fondateur : « J'accepte les 4 user stories du sprint 1 avec leurs conditions. » Les conditions ci-dessus restent à lever ; elles sont suivies dans la fiche du sprint 1.
